# Automated Sales & Inventory Analytics

**Stack:** Python (Pandas) + SQLite + Power BI

## Architecture
Raw CSV -> Python ETL -> SQLite -> SQL Analytics -> Power BI

## Dataset
- 50,000+ sales transactions
- 500 products
- 5,000 customers
- 50 stores
- 12 months of transaction history

## Python
Data ingestion, duplicate removal, missing-value handling, validation and transformation.

## SQL
Joins, CTEs, CASE logic, window functions, ranking, MoM growth and inventory-risk analysis.

## Power BI
Executive KPI dashboard covering revenue, profit, orders, product/category performance, regional trends and inventory risk.
